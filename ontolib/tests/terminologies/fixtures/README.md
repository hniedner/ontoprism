# NCIt history contract sample

`ncit-history-26.08e.txt` contains selected rows inspected in the publisher's
`https://evs.nci.nih.gov/ftp1/NCI_Thesaurus/monthly_history_26.08e.txt` on
2026-10-10. They retain the actual empty second/sixth fields and literal `null`.
The sample covers survivor/self merge rows and split targets without requiring
network access in CI. It is not a complete release history or a lifecycle census.
The command fetches the release-bound archive copy at
`https://evs.nci.nih.gov/ftp1/NCI_Thesaurus/archive/26.08e_Release/monthly_history_26.08e.txt`;
the URL above records the original sample retrieval, not the command's source URL.
